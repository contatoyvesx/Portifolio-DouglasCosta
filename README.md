# Portfólio — Douglas Costa

Portfólio profissional de Douglas Costa, reunindo projetos de desenvolvimento web, dados, automação e soluções digitais.

## Publicação

O projeto foi construído sem framework para facilitar a publicação no GitHub Pages.

Arquivos principais:

- `index.html` — estrutura e conteúdo
- `styles.css` — identidade visual e responsividade
- `script.js` — pequenos comportamentos da página

## Projetos destacados

- **Credit Risk & Pricing** — Python, Pandas, NumPy, Scikit-learn, SQL e API REST.
- **Barbearia Belarmino** — React/Vite, Express e Supabase.
- **Monteiro Transportes** — site comercial com foco em mobile e conversão.
- **Serra Turismo** — projeto web para turismo.
- **Ganho Certo** — aplicação web com React, TypeScript e Supabase.
